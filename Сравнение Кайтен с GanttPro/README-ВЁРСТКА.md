# Вёрстка лендинга «Kaiten вместо GanttPRO: российская альтернатива для планирования»

Пакет для верстальщика (чистая статика, не Next.js). Собрано Контент-заводом Кайтен.

- **Статичная вёрстка:** `index.html` (только разметка) + `styles.css` (DS-переменные +
  Tailwind-утилиты + кастомные компоненты одним файлом) + `assets/`. Без скриптов/RSC.
- **Скоуп:** `styles.scoped.css` — то же под `.kaiten-webinar`; чтобы включить, оберните
  контент в `<div class="kaiten-webinar"> … </div>` и подключите его вместо `styles.css`.
- **Машиночитаемый контент:** `content-spec.json`.

## Дизайн-система (Kaiten V01)

- **Шрифт:** Roboto (в `styles.css` — фолбэк; подключите свой / Google Fonts).
- **Контейнер:** max-width **1216px**, центрируется авто-отступами; на десктопе боковой padding 0.
- **Палитра (ключевое):**
  - Акцент / кнопки: `#7d4ccf` (soft `#efe9f9`)
  - Текст: `#2d2d2d` · вторичный `#757575`
  - Фон: `#ffffff` · секции `#f5f5f5` · границы `#e0e0e0`

## Типографика

- Бренд — по решению команды (в заголовках может быть «Кайтен» кириллицей, в подписях латиницей «Kaiten»); к единому не приводить.

### [10] FAQAccordion (id: faq)
  - Ответы на частые вопросы
  - Какие тарифы есть в Кайтен и можно ли использовать инструмент бесплатно?
  - Да, у Kaiten есть бесплатный тариф без ограничения по времени. Он подходит для небольших команд и включает базовые инструменты для управления задачами, документами и совместной работы: доски, карточки, календарь, таблицы и списки. Также доступны платные тарифы и модули — например, диаграмма Ганта, автоматизации, Scrum/Kanban-отчеты, Service Desk и ресурсное планирование.
  - Как работает пробный период?
  - После регистрации новым пользователям открывается 14-дневный пробный период со всеми модулями и функциями Kaiten. Можно протестировать диаграмму Ганта, автоматизации, Scrum-инструменты, учет времени и другие возможности без привязки банковской карты. После завершения теста аккаунт автоматически переключится на бесплатный тариф, а все данные сохранятся.
  - Как перенести проект из GanttPRO в Кайтен?
  - Проекты можно перенести через импорт CSV/XLS-файлов или JSON. Для этого нужно выгрузить данные из GanttPRO, создать рабочее пространство в Kaiten и импортировать задачи, сроки, исполнителей и структуру проекта. Это позволяет перейти на Kaiten без ручного пересоздания процессов.
  - Как начать пользоваться Кайтен?
  - Достаточно зарегистрироваться на сайте Kaiten и создать первое рабочее пространство. После этого можно выбрать подходящий формат работы — Kanban, Scrum, диаграмму Ганта или обычный список задач — пригласить команду и начать вести проекты. Для новых пользователей сразу доступен бесплатный тест всех функций системы.

## Для верстальщика: по статике

- **RSC/preload и весь фреймворк-JS убраны.** Остался ровно один маленький ванильный
  скрипт в конце `index.html` — переключение вкладок (кнопки `[data-kt-tab]` ↔ панели
  `[data-kt-panel]`). Без зависимостей; переиспользуйте или замените своим.
- **Все стили в одном `styles.css`** (внешний Tailwind-CSS + бывшие inline-`<style>` слиты).
- **CSS-переменные на месте** — классы вида `text-(--color-text-accent)` резолвятся из `:root`.
- **Скоуп** — `styles.scoped.css` (обёртка `.kaiten-webinar`, `@layer` развёрнут, чтобы утилиты
  перебивали глобальный LESS). Авто-трансформ — прогоните у себя; пуленепробиваемо — Tailwind-префикс на своей сборке.
- **SVG-иконки** — вынесены в `assets/icons/`, в разметке оставлены инлайн (красятся через currentColor).
- **Это статика:** анимации появления показаны сразу, формы ничего не отправляют.
