# Функции / Задачи — статичная выгрузка лендинга

Автономная копия страницы `/landings/kaiten-cards` («Соберите всю информацию
по задачам в карточках»). Открывается двойным кликом по `index.html`, сборка
и дев-сервер не нужны. Живая версия: https://funkcii-zadachi.vercel.app

```
index.html      разметка страницы
styles.css      все стили, 73 КБ
script.js       интерактив без React и зависимостей, 9 КБ
assets/img/     снимки интерфейса, видео первого экрана и его постер
assets/fonts/   Roboto (woff2), подключен в styles.css
```

## Что внутри

- **CSS отдельным файлом и без лишнего.** Из бандла Next.js вырезаны правила,
  чьих классов нет ни в разметке, ни в `script.js`, неиспользуемые переменные,
  `@property`, `@keyframes` и комментарии сборки: 278 → 73 КБ. В разметке нет
  ни одного `<style>`.
- **JS отдельным файлом.** В разметке нет инлайновых скриптов, `script.js`
  подключен с `defer`:
  - масштабирование моков фиксированной ширины под ширину колонки;
  - переключатель видов «Доски / Списки / Таблицы / Таймлайн / Календарь / Отчеты»;
  - стрелки и счетчик у карточек фич на мобилке и планшете, с 1024 px — сетка.
- **Разметка без служебного мусора.** Убраны маркеры React (`<!-- -->`),
  атрибуты инспектора Контент-завода (`data-comp`, `data-mock`) и баннер сборки.
  Файлы отформатированы Prettier; в HTML текст не переносится, а ручные переносы
  в заголовках записаны как `&#10;` — заголовки с `white-space: pre-line`
  выглядят как в оригинале.
- **Инлайновые `style` в моках оставлены намеренно:** это геометрия
  иллюстраций (ширины полосок, координаты, цвета меток), а не оформление.
- **Видео первого экрана** (`assets/img/tasks-hero.mp4`, 30 МБ) играет само,
  без звука и по кругу; пока кадры грузятся, виден постер
  `tasks-hero-poster.jpg`.
- **Картинки и шрифты локальные:** пути `assets/…`, файлы лежат рядом.

Проверено в браузере на 375, 1280 px: высота страницы и каждой секции совпадает
с живым лендингом, горизонтальной прокрутки нет.
