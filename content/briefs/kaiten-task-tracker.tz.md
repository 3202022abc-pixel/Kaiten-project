# ТЗ на лендинг — kaiten-task-tracker

> Сгенерировано фабрикой ТЗ (Контент-завод Кайтен) из сырых данных. Документ для ревью командой; машинный бриф — `content/briefs/kaiten-task-tracker.json`.

## Summary

Кастомный лендинг «Кайтен — таск-трекер и планировщик задач для команды и бизнеса», собирается 1-в-1 по приложенному ТЗ (docx). Режим landingMode: custom — layout из библиотеки не подбирается, состав и порядок блоков и все тексты берутся из ТЗ дословно. Структура: первый экран → три кейса с метриками → блок про контроль статусов (4 пункта) → блок доверия (3 пункта) → единая среда для компании (6 модулей) → логотипы клиентов → финальный призыв → вопросы и ответы. Между содержательными блоками ТЗ ставит самостоятельные пары кнопок «Попробовать бесплатно» / «Записаться на демо» — они выносятся отдельными блоками cta_buttons. Домен продукта — управление задачами и проектами (канбан, скрам, диаграмма Ганта, учет времени), моки берём из набора Project Management.

## Аудитория

- **Основная:** Руководители команд и отделов среднего бизнеса в России, которые ведут задачи в чатах и таблицах и теряют контроль над сроками
- **Принимает решение:** Генеральный или операционный директор, руководитель ИТ-отдела — тот, кто выбирает систему для всей компании и отвечает за сроки проектов
- **Роли:** Тимлид / руководитель проекта, Руководитель отдела (продажи, маркетинг, разработка), Генеральный директор среднего бизнеса, Операционный директор, Руководитель ИТ-отдела

**Боли:**
- Задачи живут в переписках и таблицах, поэтому руководитель узнаёт о срыве срока постфактум — таск-трекер даёт единую доску, где статус виден сразу
- Чтобы собрать статус по отделам, приходится вручную опрашивать команду и сводить отчеты — общая система показывает картину без совещаний
- У задачи нет явного ответственного и срока, поэтому работа зависает между людьми — карточка с исполнителем и датой снимает вопрос
- Перегрузка сотрудников и просроченные задачи становятся заметны поздно — визуализация показывает риск до того, как срок сорван
- Работа размазана по чатам, таблицам и отдельным сервисам — единое пространство убирает переключения и потерю данных
- Команда боится, что внедрение системы остановит работу и потребует ИТ-отдела — быстрый старт по шаблонам снимает риск

**Критерии выбора:**
- Российское ПО из реестра, данные хранятся в России
- Возможность установки на сервер компании (серверная версия)
- Поддержка нескольких методологий сразу: канбан, скрам, диаграмма Ганта
- Учет времени по задачам и проектам
- Бесплатный тариф без ограничения по времени для проверки на своей команде
- Внедрение без программирования и без привлечения интеграторов
- Возможность перенести данные из другого сервиса

**Возражения:**
- «Мы уже платим за несколько сервисов — зачем ещё один»
- «Внедрение отнимет у команды недели»
- «Нужен ИТ-отдел, чтобы всё настроить»
- «Как перенести накопленные задачи из текущего сервиса»
- «Хватит ли бесплатного тарифа, чтобы попробовать»
- «Где будут храниться наши данные»

### Вопросы и ответы
Можно ли использовать Кайтен бесплатно? Да. Вы можете вести свои задачи бесплатно без ограничения по времени. Вы можете пригласить до 5 пользователей, создать до 5 пространств и бесконечное количество документов. Платные тарифы нужны для расширенных функций и большего количества пользователей. Подробнее о тарифах
Какие методологии поддерживает Кайтен? Канбан, Скрам и Гант — можно использовать любую отдельно или сочетать в одном пространстве. Есть также учет времени по задачам и проектам. Больше о функциях — на сайте Кайтен.
Нужен ли ИТ-отдел для внедрения? Нет. Интерфейс настраивается без программирования, регистрация и первая доска занимают около 30 минут.
Как перенести данные из другого сервиса? Экспортируйте все пространства в формате PDF, HTML или CSV. Как экспортировать данные. Скачанные файлы можно будет импортировать в Кайтен — доски с помощью CSV-файла, документы — копипастом. Как перенести задачи с помощью выгрузки в формате CSV/XLS
