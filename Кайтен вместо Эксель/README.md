# Кайтен вместо Эксель — статичная выгрузка лендинга

Автономная копия страницы `/landings/kaiten-excel`. Открывается двойным кликом
по `index.html`, дев-сервер не нужен.

```
index.html          разметка страницы
styles.css          стили, 63 КБ
script.js           интерактив без React, 2 КБ
assets/brand/       картинки: снимки интерфейса, логотипы клиентов, аватары
```

## Что внутри

- **CSS отдельным файлом и без лишнего.** Из бандла вырезаны правила, чьих классов
  на странице нет: 199 → 63 КБ. Переменные темы, `:root`, теговые и базовые стили
  сохранены целиком — на них держатся палитра и типографика.
- **JS отдельным файлом.** `script.js` — ванильный, без зависимостей:
  - масштабирование моков фиксированной ширины под контейнер (в лендинге это делает React);
  - аккордеон с переключением строк;
  - слайдер представлений задач: доска → таблица → timeline → календарь. Кадры
    сменяются, только когда блок попадает в кадр при скролле.
- **Шрифт с Google Fonts.** Локальные `@font-face` вели на `/_next/static/media`
  и в отдельном файле не резолвились; заменены одной ссылкой на Roboto
  400/500/600/700. Нужен интернет — иначе сработает системный запасной шрифт.
- **Картинки локальные.** Пути переписаны с `/brand/…` на `assets/brand/…`,
  сами файлы лежат рядом.

## Как пересобрать

```bash
pnpm --filter @kaiten/web dev            # поднять дев-сервер на :3000
node scripts/build-static-html.mjs kaiten-excel "Кайтен вместо Эксель/index.html" --split-css
```

Скрипт делает всё, кроме копирования картинок и выноса скриптов в `script.js`, —
после пересборки пути к картинкам снова станут абсолютными, а скрипты вернутся
в разметку.
