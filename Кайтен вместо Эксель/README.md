# Кайтен вместо Эксель — статичная выгрузка лендинга

Автономная копия страницы `/landings/kaiten-excel`. Открывается двойным кликом
по `index.html`, сборка и дев-сервер не нужны.

```
index.html     разметка страницы
styles.css     все стили, 74 КБ
script.js      интерактив без React и зависимостей, 8 КБ
assets/brand/  картинки: снимки интерфейса, логотипы клиентов, аватары
```

## Что внутри

- **CSS отдельным файлом и без лишнего.** Из бандла Next.js вырезаны правила,
  чьих классов на странице нет, неиспользуемые переменные, `@property`,
  `@keyframes` и комментарии сборки: 286 → 74 КБ. В разметке нет ни одного
  `<style>`.
- **JS отдельным файлом.** В разметке нет инлайновых скриптов, `script.js`
  подключен с `defer`:
  - масштабирование моков фиксированной ширины под ширину колонки;
  - слайдер представлений задач: кадры сменяются, только когда блок в зоне видимости;
  - карусель модулей: стрелки и счетчик на мобилке и планшете, с 1280 px — сетка;
  - отзывы: листалка появляется, когда карточки не помещаются в ширину.
- **Разметка без служебного мусора.** Убраны маркеры React (`<!-- -->`),
  атрибуты инспектора Контент-завода (`data-comp`, `data-mock`) и баннер сборки.
  Файлы отформатированы Prettier; в HTML переносы и пробелы внутри текста
  не тронуты — заголовки с `white-space: pre-line` выглядят как в оригинале.
- **Инлайновые `style` в моках оставлены намеренно:** это геометрия
  иллюстраций (ширины полосок, координаты, цвета меток), а не оформление.
- **Шрифт Roboto с Google Fonts** (400/500/600/700). Без интернета сработает
  системный запасной шрифт.
- **Картинки локальные:** пути `assets/brand/…`, файлы лежат рядом.
