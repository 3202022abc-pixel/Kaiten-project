# Кайтен on-premise — лендинг

Статический лендинг коробочной версии Кайтен. Без сборки: открывается как есть,
любой статический хостинг подойдет.

Прод: https://kaiten-onpremise-deploy.vercel.app

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | вся разметка страницы |
| `styles.css` | все стили одним файлом: база дизайн-системы V01, мини-мокапы модулей, стили лендинга |
| `script.js` | появление блоков по скроллу, карусели, аккордеоны, анимации иллюстраций |
| `assets/` | картинки: сертификаты, скриншоты интерфейсов, логотипы, иллюстрации |

`styles.css` собран из трех бывших файлов и идет тремя секциями в том же порядке,
в каком они подключались: база → мини-мокапы → лендинг. Порядок важен, стили
лендинга перекрывают базу.

**Важно:** у `styles.css` в `index.html` стоит версия в query-строке
(`styles.css?v=915`). После каждой правки стилей увеличивайте число, иначе
браузер и CDN отдадут старый файл.

## Брейкпоинты

| Диапазон | Раскладка |
|---|---|
| `≥1280` | десктоп, контейнер 1216px, поля 32 |
| `1024–1279` | планшет с десктопной раскладкой, поля 24, модули в две строки по три карточки |
| `768–1023` | планшет, поля 24, модули в две строки по две карточки |
| `≤767` | мобилка, поля 16, модули аккордеоном |

Шаг сеток между блоками — 24px на планшете и на десктопе.

## Анимации

Блоки с классом `rv` получают `on` от IntersectionObserver в `script.js` —
на этом построено появление по скроллу. Раскрытия (FAQ, аккордеон модулей)
анимируют высоту через `height: 0 → auto` с `interpolate-size: allow-keywords`.
Все анимации выключаются при `prefers-reduced-motion: reduce`.
